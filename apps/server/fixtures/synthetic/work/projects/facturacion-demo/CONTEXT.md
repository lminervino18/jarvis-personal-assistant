# Facturación demo: librería ficticia de cálculo de facturas

Proyecto sintético para probar el flujo de tareas delegadas. No contiene datos reales.

- Node 24, módulos ESM (`.mjs`), sin dependencias externas.
- Pruebas con el runner nativo: `node --test` desde la raíz del repositorio.
- Los montos se redondean a dos decimales al final del cálculo, nunca en pasos intermedios.
- El IVA por defecto es 21 %.
