Política de privacidad de J.A.R.V.IS

Actualizada el 22 de noviembre de 2026.

Qué es

J.A.R.V.IS es un asistente personal de uso privado. Lo usa una sola persona, su dueño, y no está disponible para el público.

Qué datos de Google usa

  • Leer Gmail (gmail.readonly): busca y lee correos solo cuando el dueño lo pide en la conversación.
  • Enviar correos (gmail.send): manda un correo solo después de que el dueño confirma el destinatario, el asunto y el texto exactos. No puede leer, cambiar ni borrar correos con este permiso.
  • Correo de la cuenta (email, openid): para saber qué cuenta se conectó.

Cómo se guardan

El token de acceso se guarda cifrado en el servidor privado del asistente. El contenido de los correos no se guarda: se consulta cuando hace falta y se muestra en la conversación del dueño.

Con quién se comparten

Con nadie. Para responder, el asistente usa un modelo de lenguaje (Claude, de Anthropic) que procesa lo que el dueño pide en ese momento. Los datos no se venden, no se usan para publicidad y no se usan para entrenar modelos.

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo quitar el acceso

El acceso se revoca en cualquier momento desde myaccount.google.com/permissions. Para cualquier consulta, escribí al correo de soporte que figura en la pantalla de autorización de Google.
