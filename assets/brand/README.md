# Brand assets

Original, code-native artwork for this personal project. The circular core with segmented cyan and blue rings is inspired by the general aesthetic of film AI interfaces; it does not reproduce any official logo or asset from Marvel or Disney, and the project is not affiliated with them or with Anthropic.

| File | Use |
| - | - |
| `logo-mark.svg` | Core mark, 512×512 viewBox |
| `logo-wordmark.svg` | Mark with the "J.A.R.V.IS" wordmark (text converted to paths) |
| `favicon.svg`, `favicon.ico` | Browser tab icon (simplified for small sizes) |
| `icon-192.png`, `icon-512.png` | PWA icons (`purpose: any`) |
| `icon-maskable-512.png` | PWA maskable icon (content inside the safe zone) |
| `apple-touch-icon.png` | iOS home screen icon, 180×180 |
| `banner.svg`, `banner.png` | README banner |

Palette: background `#050B18`, cyan `#46E3FF`, light cyan `#8FEFFF`, blue `#2B5CFF`, amber accent for states `#F5B841`. Wordmark set in Inter Display SemiBold (SIL Open Font License), converted to outlines.

The PNGs are rendered from the SVGs with Inkscape. Licensed with the rest of the repository (MIT).
